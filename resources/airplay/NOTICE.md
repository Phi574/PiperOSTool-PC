# PiperOS AirPlay receiver

`PiperAirPlayReceiver.exe` is a small PiperOS launcher for the bundled
UxPlay Windows receiver (`resources/airplay/uxplay`). UxPlay and its runtime
dependencies retain their own licenses. Source and licensing information are
available at https://github.com/Legato666/uxplay and the upstream Windows
distribution at https://github.com/leapbtw/uxplay-windows.

This component receives ordinary AirPlay screen mirroring. It does not bypass
protected playback or Apple security controls.
